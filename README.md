# GTM Agentic Skills

AI skills for marketing with a focus on account-based-marketing specific strategies.

## Usage

Each skill's own README has its setup and options. Run the script, or, if it generates a prompt, paste the output into whatever AI tool you're using.

## How these work

Most generate plain text (a prompt, a checklist, a report) instead of calling an AI API directly, so they work with any AI tool.

## Requirements

Most skills use Python 3.7+ (a default, not a rule) and need only the standard library. A few need a short `pip install`, listed in that skill's README.
